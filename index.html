This is a simple, no-frills blackjack practice applet for basic strategy and Hi-Lo counting inspired by brendansudol's Hi-Lo counting game. Doubling is allowed and surrendering is not.

Basic strategy gives the best possible moves that can be made without additional information and can be found in the toggleable table at the bottom of this page. Hi-Lo counting is a simple but effective card counting system where a score is incremented for cards 2-6, decremented for cards 10-A, and unchanged for cards 7-9.

The source code for this application can be found on GitHub.

Press Place to begin the game.
